# 👻 Shinchan: Haunted Runner

## 🎮 About the Game
Shinchan: Haunted Runner is a 2D arcade running game developed for the Multimedia Systems Lab. Shinchan is trapped inside a dangerous haunted house and must escape by avoiding ghosts, dodging obstacles, and collecting magical moon crystals. After collecting the required crystals, he can unlock the portal and enter the next haunted house.

Each new level becomes more challenging, with faster movement, more hazards, and a scarier atmosphere.

## ✨ Features
- Haunted house theme with spooky visuals.
- Shinchan as the main playable character.
- Three-lane endless runner gameplay.
- Swipe controls for mobile devices.
- Keyboard controls for computers.
- Collectible moon crystals.
- Ghosts and obstacles to avoid.
- Multiple levels with increasing difficulty.
- Score, lives, and level progression.
- Portal system to advance to the next haunted house.
- Game-over and restart functionality.
- Sound effects for an immersive experience.

## 🕹️ Controls

### Mobile
- Swipe left: Move to the left lane.
- Swipe right: Move to the right lane.
- Swipe up: Jump.
- Swipe down: Slide.

### Computer
- Left Arrow: Move left.
- Right Arrow: Move right.
- Up Arrow: Jump.
- Down Arrow: Slide.

## 📜 Game Rules
1. Start the game and help Shinchan escape the haunted house.
2. Collect the required moon crystals to unlock the portal.
3. Avoid ghosts and other dangerous obstacles.
4. Reach the portal to advance to the next level.
5. Each new haunted house increases the difficulty.
6. Avoid collisions and try to survive as long as possible.
7. If all lives are lost, the game ends. Restart to try again.

## 🌟 Unique Customization
The game uses a haunted-house escape theme with progressively harder levels. Instead of completing just one stage, Shinchan must escape multiple haunted houses. The game combines collectible objectives, obstacle avoidance, mobile swipe controls, and increasing difficulty.

## 🚀 How to Run Locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate `index.html`.
4. Open it in a modern web browser.
5. Start playing!

Keep all JavaScript, CSS, image, and sound files in their required relative locations.

## 🌐 Deployment on Vercel
1. Upload the project files to a GitHub repository.
2. Visit https://vercel.com/new.
3. Import the GitHub repository.
4. Set the Root Directory to the folder containing `index.html`.
5. Select **Other** as the framework preset.
6. Leave the build command blank for a static HTML project.
7. Click **Deploy**.
8. Open the generated website URL to play the game.

## 🧠 Algorithm
1. Initialize the player, game state, score, lives, and level.
2. Read keyboard or touch input.
3. Update Shinchan's lane and jumping or sliding movement.
4. Move obstacles and collectibles toward the player.
5. Detect collisions with obstacles, ghosts, and collectibles.
6. Update score and lives based on collisions.
7. Unlock the portal when the required collectibles are gathered.
8. Increase difficulty when the player advances to the next level.
9. Display the game-over screen when the player loses all lives.
10. Allow the player to restart and play again.

## 💥 Collision Detection
Collision detection checks whether the player's bounding area overlaps an obstacle or collectible. When a collectible is touched, it is collected and the score or objective count is updated. When the player hits a hazard, a life is lost or another penalty is applied.
